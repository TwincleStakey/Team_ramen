# Tools

임시 그림을 찍는 파이썬 스크립트. 프로젝트 뿌리에서 돌린다.

```
python Tools/makeart.py     # Assets/Art/화면/우주 배경.png (640x360)
python Tools/makebolt.py    # Assets/Art/나머지/번개.png   (64x64 칸 6개) — 지금은 안 쓴다
python Tools/makecut.py     # 큰번개.png(640x360) · 오우라.png(160칸 8개) · 따봉.png(40x40)
```

둘 다 **손으로 그린 그림이 들어오면 버려도 되는 자리 채우기**다.
파일만 같은 이름·같은 크기로 갈아 끼우면 빌더가 그대로 읽는다.

난수 씨앗이 고정돼 있어서 다시 돌려도 같은 그림이 나온다.
별자리나 번개 모양을 바꾸고 싶으면 파일 위쪽 `random.seed` 를 고친다.

`번개.png`(작은 것 여섯 줄기)는 흩뿌리는 연출을 쓰던 때 만든 것이다.
지금은 `큰번개.png` 한 방으로 바뀌어 아무도 안 읽는다. 되살릴 일이 없으면 지워도 된다.

## outline.py — 검은 외곽선 두께 맞추기

```bash
python Tools/outline.py        # 재기만 한다 (고치지 않는다)
```

에셋마다 검은 외곽선 두께가 제각각이라 나란히 놓으면 겉돈다.
**그릇(1픽셀)이 기준**이고, 두꺼운 것은 바깥 겹을 지워 1픽셀만 남긴다.

2026-09-10 에 타래통 3종(3겹)과 향미유통(2겹)을 1겹으로 깎았다.
원본은 `쓰레기통/외곽선_원본/` 에 있다. 나머지 에셋은 이미 1겹이었다.

새 그림을 받으면 이 스크립트로 먼저 재 보고, 2겹 이상이면 깎아서 넣을 것.

전부 `PIL`(Pillow)이 필요하다.
